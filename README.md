# Day 05 - OOP Notebooks

This folder contains Jupyter notebooks for day 05, focusing on Python
object-oriented programming (OOP) concepts.

## Illustrated Overview

```
day05/
├── intro_to_OOP.ipynb
│   ├─ Basics: classes, instances, methods
│   ├─ Object creation: __init__
│   └─ Dynamic attributes & __dict__
├── oop_principles.ipynb
│   ├─ Static vs class methods
│   ├─ Inheritance & overriding
│   ├─ Encapsulation (public/protected/private)
│   ├─ Properties (@property, setters)
│   └─ Custom exceptions
└── main.py
    └─ Support code (optional)
```

## Contents

- `intro_to_OOP.ipynb` - Introductory OOP concepts and examples.
- `oop_principles.ipynb` - Deeper OOP principles: inheritance, access
  modifiers, properties, and custom exceptions.
- `main.py` - Supporting Python script (if needed by the lesson).

## How to Use

Open the notebooks with Jupyter Lab/Notebook or VS Code/Cursor.

```bash
jupyter lab
```

Then open the notebook from the file browser.

## Learning Path

1. Start with `intro_to_OOP.ipynb` for fundamentals.
2. Continue to `oop_principles.ipynb` for advanced concepts.
3. Use `main.py` only if the lesson references it.
