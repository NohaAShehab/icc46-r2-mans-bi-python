Python List Operations

Lists are one of the most versatile data structures in Python. They are ordered, mutable, and allow duplicate elements. Explore common list operations below.

List Operations & Methods

Creating Lists

Lists can be created using square brackets or the list() constructor.

# Creating a list fruits = ["apple", "banana", "cherry"] numbers = list(range(1, 6)) empty_list = []

Accessing Elements

Access list items by index (positive or negative).

fruits = ["apple", "banana", "cherry"] print(fruits[0]) # First item: "apple" print(fruits[-1]) # Last item: "cherry" print(fruits[1:3]) # Slicing: ["banana", "cherry"]

Adding Elements

Use append(), insert(), or extend() to add items.

fruits = ["apple", "banana"] fruits.append("orange") # Adds to the end fruits.insert(1, "mango") # Inserts at index 1 fruits.extend(["grape", "kiwi"]) # Adds multiple items

Removing Elements

Use remove(), pop(), or clear() to remove items.

fruits = ["apple", "banana", "cherry", "banana"] fruits.remove("banana") # Removes first "banana" popped = fruits.pop() # Removes and returns last item fruits.pop(0) # Removes item at index 0 # fruits.clear() # Removes all items

List Comprehension

A concise way to create lists based on existing lists.

# Create a list of squares squares = [x**2 for x in range(1, 6)] # Result: [1, 4, 9, 16, 25] # With condition even_squares = [x**2 for x in range(1, 11) if x % 2 == 0] # Result: [4, 16, 36, 64, 100]

Sorting & Reversing

Use sort(), sorted(), and reverse().

numbers = [5, 2, 8, 1, 9] numbers.sort() # Sorts in-place: [1, 2, 5, 8, 9] sorted_nums = sorted(numbers, reverse=True) # Returns new sorted list numbers.reverse() # Reverses the list in-place

Other Useful Methods

len(), index(), count(), copy().

fruits = ["apple", "banana", "cherry", "banana"] length = len(fruits) # Returns 4 idx = fruits.index("banana") # Returns 1 count = fruits.count("banana") # Returns 2 fruits_copy = fruits.copy() # Creates a shallow copy
